📍 WHAT EACH TAB TEACHES YOU
1
🎯 Zero-Shot — Just ask, no examples
Direct instruction. Works for simple tasks. "Classify this ticket as Billing / Technical / General."
2
📚 Few-Shot — Teach by example
Show 2–5 input/output pairs. Model learns your exact format and tone from examples.
3
🧠 Chain-of-Thought — Think step by step
Force the model to reason before answering. Dramatically improves complex decisions and accuracy.
4
🤖 ReAct — Reason + Act in a loop
Model alternates Thought → Action → Observation. Enables AI agents to use tools and self-correct.
5
🛠️ Advanced Techniques
Role prompting, delimiters, structured output, system vs user prompts, negative examples.
6
⚡ Live Claude API Demo
Run all 4 techniques live with your own API key. Token meter shows cost in real-time.
7
💰 Token Optimisation
Cut prompt costs by 40–70% using compression, caching, smart max_tokens, and reuse patterns.
8
📊 Prompt Evaluation
How to score and compare prompts systematically. Test data, metrics, and A/B framework.

📚 Citations & Free Resources
1
Wei et al. (2022) — "Chain-of-Thought Prompting Elicits Reasoning in LLMs" — Google Brain FREE
The original paper showing that adding "Let's think step by step" dramatically improves reasoning on math and logic tasks.
🔗 arxiv.org/abs/2201.11903
2
Yao et al. (2022) — "ReAct: Synergising Reasoning and Acting in Language Models" FREE
Introduces the Thought → Action → Observation loop that powers modern AI agents like LangChain's AgentExecutor.
🔗 arxiv.org/abs/2210.03629
3
Anthropic Prompt Engineering Guide FREE
Official guide covering Claude-specific best practices: XML tags, system prompts, role assignment, output formatting, and long-document handling.
🔗 docs.anthropic.com — Prompt Engineering Overview
4
OpenAI Prompt Engineering Guide FREE
Covers six strategies: write clear instructions, provide reference text, split into subtasks, give time to think, use external tools, test changes systematically.
🔗 platform.openai.com/docs/guides/prompt-engineering
5
Prompt Engineering Guide — Dair.ai FREE
Comprehensive open-source guide covering all techniques: Zero/Few-Shot, CoT, Self-Consistency, ToT, ReAct, RAG, and adversarial prompting.
🔗 promptingguide.ai
6
Brown et al. (2020) — "Language Models are Few-Shot Learners" — OpenAI (GPT-3 paper) FREE
Introduced Few-Shot prompting as an emergent capability of large language models. Foundation of modern in-context learning.

7
